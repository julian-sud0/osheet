What's faked vs real

Real: all navigation, all logging, weather changes with data, day-counter, week-3 demo data preloads after first log.

Faked: PDF actually opens a printable view (try Save PDF). No backend — refresh wipes everything. Photos are placeholder. Biometric is a tap.

Demo shortcut: press D for the "Week 3 with real data" state. Press R to reset.
